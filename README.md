## 🎯 Что такое CodeMind?

CodeMind — это open-source веб-приложение, которое позволяет искать код в GitHub-репозиториях **по смыслу**, а не по точному совпадению слов.

**Пример:** вы ищете *"функция для парсинга JSON"*, а CodeMind находит код, где написано `def load_config(): return json.load(f)`, даже если в нём нет слов "парсинг" или "функция".

### ✨ Преимущества

- **Zero-config** — работает из коробки, без установки и настройки
- **Приватность** — весь код выполняется в вашем браузере, данные не отправляются на сервер
- **Настоящая семантика** — использует Hugging Face Embeddings (модель `all-MiniLM-L6-v2`)
- **Бесплатно** — никаких подписок и скрытых платежей
- **Open Source** — форкайте, улучшайте, используйте как хотите

## 🚀 Как пользоваться

### Быстрый старт (публичные репозитории)

1. Откройте [CodeMind](https://syntropy-lab-ai.github.io/codemind/)
2. Введите GitHub username (например, `octocat`)
3. Введите поисковый запрос (например, `функция для работы с API`)
4. Нажмите **Найти**
5. Дождитесь анализа репозиториев (прогресс-бар покажет статус)
6. Изучите результаты — каждый содержит имя функции, фрагмент кода и процент совпадения

### Расширенный режим (приватные репозитории)

Если вы хотите искать по своим **приватным** репозиториям:

1. Создайте GitHub Personal Access Token (инструкция ниже)
2. Вставьте токен в поле **GitHub Token** на сайте
3. Токен сохранится в вашем браузере и будет использоваться автоматически

---

## 🔑 Как создать GitHub Personal Access Token

1. Откройте [GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)](https://github.com/settings/tokens)
2. Нажмите **Generate new token (classic)**
3. Дайте токену имя (например, `CodeMind`)
4. Выберите срок действия (например, 90 дней)
5. В правах доступа (scopes) выберите **только `repo`** (доступ только к чтению репозиториев)
6. Нажмите **Generate token**
7. **Скопируйте токен** (он показывается только один раз!)
8. Вставьте токен в поле "GitHub Token" на сайте CodeMind

## 🔒 Безопасность

- **Токен хранится только в вашем браузере** (localStorage) и никуда не отправляется
- **Мы не используем серверы** — весь код выполняется локально в вашем браузере
- **Ваш код не покидает ваш компьютер** — мы только читаем его через GitHub API для анализа
- **Вы можете удалить токен** в любой момент, очистив localStorage браузера
- **Используйте токен с минимальными правами** (только `repo`) для максимальной безопасности

## 🧠 Как это работает
┌─────────────────────────────────────────────────────────────┐
│ Браузер пользователя │                                       
├─────────────────────────────────────────────────────────────┤
│ 1. GitHub API → получаем список репозиториев и файлов │
│ 2. Извлекаем функции и классы из кода │
│ 3. Hugging Face API → получаем векторные представления │
│ 4. IndexedDB → кешируем вектора для быстрого повторного │
│ поиска │
│ 5. Cosine Similarity → находим ближайшие по смыслу │
│ 6. Показываем результаты с подсветкой синтаксиса │
└─────────────────────────────────────────────────────────────┘

### Технологии

- **Frontend:** HTML5, Vanilla JavaScript (ES6+ модули), Tailwind CSS
- **API:** GitHub REST API, Hugging Face Inference API
- **Хранение:** IndexedDB (кеш векторов), localStorage (токен)
- **Подсветка синтаксиса:** Highlight.js
- **Хостинг:** GitHub Pages
