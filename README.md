**Семантический поиск по GitHub-репозиториям — прямо в браузере, без серверов.**

## 🎯 Что это

CodeMind — open-source веб-приложение, которое ищет код в GitHub-репозиториях **по смыслу**, а не по точному совпадению слов.

**Пример:** вы ищете *"как извлекаются функции из исходного кода"*, а CodeMind находит `extractCodeBlocks` в `embeddings.js`, даже если в коде нет слов «извлекаются функции».

### ✨ Ключевые преимущества

- **Zero-config** — открыл, вбил username, ищет. Установка не нужна.
- **Настоящая семантика** — нейросетевая модель работает **внутри вашего браузера** (WebAssembly), а не на чужом сервере.
- **Приватность** — ваш код и запросы не отправляются ни на какие серверы. Токен живёт только в localStorage.
- **Отказоустойчивость** — если модель не загрузилась (сеть/блокировка), приложение само переключается на лексический поиск и **не падает**.
- **Бесплатно навсегда** — хостинг на GitHub Pages, модель и API открытые.
- **Open Source** — форкайте, улучшайте, используйте как хотите.

## 🧠 Как это работает

┌──────────────────────────────────────────────────────────────┐

│ Ваш браузер (GitHub Pages) │                                 

├──────────────────────────────────────────────────────────────┤

│ 1. GitHub API → список репозиториев и файлов кода │ 

│ 2. Извлечение блоков (функции/классы) из исходников │           

│ 3. cleanCode() → убираем строковые литералы (UI-шум), │       

│ сохраняем комментарии (они несут смысл) │                     

│ 4. Transformers.js (модель paraphrase-multilingual-MiniLM) │

│ → вектор 384-мерный, прямо в браузере │                       

│ 5. IndexedDB → кеш векторов (TTL 7 дней, версия v3) │           

│ 6. Косинусное сходство + буст по имени → ранжирование │      

│ 7. Результаты с подсветкой синтаксиса и ссылкой на GitHub │    
└──────────────────────────────────────────────────────────────┘


### Модель

Используется **`Xenova/paraphrase-multilingual-MiniLM-L12-v2`** — мультиязычная модель (50+ языков, включая русский), возвращающая векторы размерности 384. Загружается через [Transformers.js](https://github.com/xenova/transformers) и кэшируется в браузере, поэтому повторные запуски быстрые.

> ⚠️ **Важно про русский:** короткие запросы из 1–2 слов ранжируются шумно — это фундаментальное свойство эмбеддингов, а не баг. Для точного поиска формулируйте запрос как фразу (5–10 слов).

### Fallback

Если модель не удалось загрузить (блокировка CDN, слабый интернет), включается встроенный **лексический поиск** (TF-IDF + хеширование в тот же 384-мерный вектор). Режим работы показан индикатором под заголовком:
- ⚡ **нейросетевой поиск** — модель работает
- 🛡 **лексический поиск** — сработал fallback (офлайн-режим)

## 🚀 Как пользоваться

### Базовый режим (публичные репозитории)

1. Откройте [CodeMind](https://syntropy-lab-ai.github.io/codemind/).
2. **GitHub Username** — введите логин (например, `octocat`).
3. **Поисковый запрос** — опишите, что ищете (например, `обработка ошибок сети`).
4. Нажмите **Найти**. При первом запуске модель скачается (~20–60 сек), дальше — мгновенно.

### Расширенный режим (приватные репозитории + лимиты)

По умолчанию GitHub API даёт **60 запросов/час** на IP. Для приватных репо и лимита **5000/час** нужен токен.

1. Откройте [GitHub → Personal access tokens (classic)](https://github.com/settings/tokens).
2. **Generate new token (classic)**.
3. Note: `CodeMind`, Expiration: по вкусу.
4. Scopes: **только `repo`** (минимально необходимый доступ).
5. Скопируйте токен (показывается один раз).
6. Вставьте в поле **GitHub Token** на сайте.

> 💡 Используйте **classic**-токен, а не fine-grained: fine-grained часто отдаёт 403 на эндпоинт списка репозиториев пользователя.

## 🔒 Безопасность

- **Токен** хранится только в `localStorage` вашего браузера и отправляется напрямую в GitHub API. Ни один промежуточный сервер его не видит — серверов у нас нет.
- **Код** читается через публичный GitHub API; для приватных репо — под вашим токеном.
- **Векторы** кешируются в `IndexedDB` вашего браузера и никуда не уходят.
- **Удалить токен** в любой момент: кнопка «🗑 Очистить кеш» + очистка localStorage в DevTools.
- **Минимальные права** токена (`repo` read) — даже при утечке нельзя ничего изменить.
